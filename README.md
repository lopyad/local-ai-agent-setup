# 로컬 AI 에이전트 설정 가이드 (Windows 11)

이 가이드는 Ollama와 Continue.dev를 사용하여 Windows 11 환경에서 로컬 AI 에이전트를 설정하는 절차를 설명합니다. 제공된 `Modelfile`과 `.continue.config.yaml` 파일을 활용합니다.

## 1. 사전 준비 사항

- **Ollama 설치**: [ollama.com](https://ollama.com/)에서 Windows용 Ollama를 다운로드하여 설치하세요.
- **VS Code 및 Continue 설치**: VS Code를 실행하고 Extension 마켓플레이스에서 **Continue**를 설치하세요.

---

## 2. Ollama 모델 생성 (`Modelfile` 사용)

`Modelfile`은 로컬에 있는 GGUF 모델 파일을 Ollama에서 사용할 수 있도록 정의하는 설정 파일입니다.

1.  **Modelfile 수정**:
    - `Modelfile`을 열고 첫 번째 줄의 경로를 실제 GGUF 파일이 있는 경로로 수정하세요.
    - 예: `"FROM "C:\YOUR\DIR\gemma-4-E4B-it-GGUF\gemma-4-E4B-it-Q4_K_M.gguf"`
2.  **터미널 실행**: PowerShell을 엽니다.
3.  **모델 생성 명령 실행**: `Modelfile`이 있는 디렉토리로 이동한 후 다음 명령어를 입력합니다.
    ```powershell
    ollama create google/gemma-4-e4b -f Modelfile
    ```
4.  **확인**: 모델이 정상적으로 생성되었는지 확인합니다.
    ```powershell
    ollama list
    ```

---

## 3. Continue.dev 설정 (`.continue.config.yaml` 사용)

Continue.dev가 생성된 Ollama 모델을 인식하고 사용할 수 있도록 설정 파일을 적용합니다.

1.  **설정 파일 위치 이동**:
    - Windows 탐색기 주소창에 `%USERPROFILE%\.continue`를 입력하여 이동합니다.
    - (일반적으로 `C:\Users\<사용자이름>\.continue` 경로입니다.)
2.  **config.yaml 적용**:
    - 해당 폴더에 기존 `config.yaml` (또는 `config.json`)이 있다면 백업해두세요.
    - 프로젝트 폴더의 `.continue.config.yaml` 파일 내용을 복사하여 `%USERPROFILE%\.continue\config.yaml`에 덮어쓰거나 내용을 병합합니다.

3.  **Continue 재시작**:
    - VS Code에서 Continue 사이드바를 열고, 모델 선택 드롭다운에서 `gemma4-e4b` (Chat용) 모델이 나타나는지 확인합니다.
